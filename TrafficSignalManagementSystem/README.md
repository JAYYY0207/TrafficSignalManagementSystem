# Traffic Signal Management System

A Java Swing-based simulation of an intelligent traffic signal management system,
featuring vehicle generation, density-based signal scheduling, emergency vehicle
priority, and peak-hour traffic analysis.

## Structure
See `docs/` for SRS, UML diagram, flowchart, and project report.

## Running
Open in IntelliJ IDEA, mark `src` as Sources Root, `test` as Test Sources Root,
`resources` as Resources Root, then run `src/main/Main.java`.
